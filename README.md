# That '80s Game


## Play in Browser: https://hiddenwaffle.github.io/that80sgame

_Escape the arcade and fight in the Cold War_

![The title screen of That '80s Game](public/preview.jpg)

Originally written in 2003 for RPGDX's [Compo Nostos](https://rpgdx.net/showgame.php?project_id=178). Remastered in 2026 for no particular reason whatsoever.

## Developer mode

With Node 24 installed, run:

```sh
npm install
npm run dev
```
